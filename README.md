# E-Commerce Sales Analytics

This is a simple e-commerce sales analytics project made using Python and NumPy.

## Features

- Total orders and total revenue
- Average and median order value
- Highest and lowest order value
- Top spending customer
- Most active customer
- Best-selling and lowest-selling products
- Top 3 products
- Payment method analysis
- Revenue contribution by payment method

## NumPy Concepts Used

- NumPy arrays
- Array slicing
- Boolean indexing
- `np.unique()`
- `np.sum()`
- `np.mean()`
- `np.median()`
- `np.max()`
- `np.min()`
- `np.std()`
- `np.argmax()`
- `np.argmin()`
- `np.argsort()`
